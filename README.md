# bodycam-proc

Pour commencer : `DEMARRER.md`.

Un monde généré par code, filmé comme par une caméra-piéton, dans le navigateur. Aucun asset.

- `npm run build` assemble `src/` et `scenes/` en une page autonome, `dist/index.html`.
- `docs/principes.md` explique ce qu'on cherche et pourquoi.
- `docs/fiche-de-lieu.md` et `docs/contrat-histoire.md` décrivent les deux formats que l'IA écrit.
- `docs/rendu.md` liste les pistes de rendu, faites et à faire.
- `CLAUDE.md` donne les règles et les conventions pour travailler dans ce dépôt.

`histoires/chateau-minuit.json` est un exemple de contrat d'histoire. Il n'est pas jouable : il demande un kit château qui n'existe pas encore. L'histoire jouable est celle de `scenes/02-grands-avaux-nuit.json`.

État : prototype. Vérifié en rendu logiciel uniquement, pas encore mesuré sur téléphone.
